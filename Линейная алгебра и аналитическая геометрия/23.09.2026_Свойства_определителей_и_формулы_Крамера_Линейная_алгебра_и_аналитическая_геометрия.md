## Свойства определителей

Для квадратной матрицы $A$:

1. $\det A^T=\det A$.
2. Перестановка двух строк или столбцов меняет знак определителя.
3. При двух одинаковых либо пропорциональных строках или столбцах определитель равен нулю.
4. Общий множитель элементов одной строки можно вынести за знак определителя.
5. Нулевая строка или столбец даёт нулевой определитель.
6. Определитель линеен по каждой отдельной строке или столбцу при фиксированных остальных.
7. Прибавление к строке другой строки, умноженной на число, не меняет определитель.
8. Сумма произведений элементов строки на алгебраические дополнения другой строки равна нулю.
9. $\det(AB)=\det A\det B$ для квадратных матриц одного порядка.

Линейность по строке означает:

$$\det(\ldots,\alpha u+\beta v,\ldots)=\alpha\det(\ldots,u,\ldots)+\beta\det(\ldots,v,\ldots).$$

Прибавление кратной другой строки сохраняет определитель, поскольку дополнительное слагаемое содержит две одинаковые строки и равно нулю.

## Треугольная матрица

**Определитель треугольной матрицы равен произведению диагональных элементов**:

$$\det A=a_{11}a_{22}\cdots a_{nn}.$$

Это позволяет вычислять определитель методом исключения. Нужно отмечать перестановки строк и деления строк на числа: они влияют на итоговое значение.

Например,

$$\begin{vmatrix}1&2&3\\4&5&6\\9&12&15\end{vmatrix}\xrightarrow{R_2-4R_1,\ R_3-9R_1}\begin{vmatrix}1&2&3\\0&-3&-6\\0&-6&-12\end{vmatrix}=0,$$

поскольку третья строка вдвое больше второй.

## Пример определителя четвёртого порядка

$$A=\begin{pmatrix}2&1&3&5\\1&-1&3&2\\-1&4&2&7\\3&-1&4&1\end{pmatrix}.$$

Переставим первые две строки: знак определителя меняется. Затем выполним $R_2\leftarrow R_2-2R_1$, $R_3\leftarrow R_3+R_1$, $R_4\leftarrow R_4-3R_1$:

$$\det A=-\begin{vmatrix}1&-1&3&2\\0&3&-3&1\\0&3&5&9\\0&2&-5&-5\end{vmatrix}=-\begin{vmatrix}3&-3&1\\3&5&9\\2&-5&-5\end{vmatrix}.$$

Последний определитель равен $3\cdot20+3\cdot(-33)-25=-64$. Следовательно, **$\det A=64$**.

## Алгебраическое дополнение с параметром

Пусть

$$A=\begin{pmatrix}2&0&3&-2\\5&-1&4&0\\-3&d&3&1\\0&-1&3&1\end{pmatrix},\qquad A_{23}=64.$$

Удалив вторую строку и третий столбец, получаем

$$A_{23}=-\begin{vmatrix}2&0&-2\\-3&d&1\\0&-1&1\end{vmatrix}=-(2d-4)=4-2d.$$

Условие $4-2d=64$ даёт **$d=-30$**. Здесь минор не следует путать с алгебраическим дополнением: для позиции $(2,3)$ знак отрицательный.

## Формулы Крамера

Для квадратной системы $AX=B$ обозначим $\Delta=\det A$, а $\Delta_j$ — определитель, в котором столбец $j$ заменён столбцом $B$.

**Если $\Delta\ne0$, система имеет единственное решение**:

$$x_j=\frac{\Delta_j}{\Delta},\qquad j=1,\ldots,n.$$

При $\Delta=0$ эти формулы применять нельзя. Если хотя бы один $\Delta_j\ne0$, система несовместна. Если все $\Delta_j=0$, требуется дополнительный анализ: этого условия в общем случае недостаточно, чтобы заключить совместность. Общий критерий использует ранги основной и расширенной матриц.

## Решение системы по Крамеру

$$\begin{cases}x-2y+4z=1,\\2x+2y-4z=2,\\-x-y+z=4.\end{cases}$$

Матрица коэффициентов и столбец свободных членов:

$$A=\begin{pmatrix}1&-2&4\\2&2&-4\\-1&-1&1\end{pmatrix},\qquad B=\begin{pmatrix}1\\2\\4\end{pmatrix}.$$

Вычисление определителей даёт

$$\Delta=-6,\quad\Delta_x=-6,\quad\Delta_y=60,\quad\Delta_z=30.$$

Поэтому $x=1$, $y=-10$, $z=-5$. Подстановка: $1+20-20=1$, $2-20+20=2$, $-1+10-5=4$.

## Главное

- Прибавление кратной строки не меняет определитель; перестановка меняет его знак.
- Для треугольной матрицы достаточно перемножить диагональные элементы.
- В алгебраическом дополнении учитывают множитель $(-1)^{i+j}$.
- Формулы Крамера дают решение только при ненулевом определителе системы.
- При нулевом определителе совместность устанавливают дополнительно.
