## План решения задач с матрицами

В задачах на алгебраические дополнения, определитель и обратную матрицу порядок работы следующий:

1. Для каждого требуемого элемента вычислить минор $M_{ij}$ и дополнение $A_{ij}=(-1)^{i+j}M_{ij}$.
2. Найти $\det A$ удобным разложением или элементарными преобразованиями.
3. При $\det A\ne0$ найти $A^{-1}$.
4. Проверить произведение $AA^{-1}=E$.

Для матрицы

$$A=\begin{pmatrix}1&0&-5&6\\3&4&8&5\\0&-2&0&4\\0&0&0&1\end{pmatrix}$$

удобно разложить определитель по последней строке:

$$\det A=\begin{vmatrix}1&0&-5\\3&4&8\\0&-2&0\end{vmatrix}=16+30=46\ne0.$$

Следовательно, обратная существует. Наличие нижних нулей помогает вычислению, но матрица целиком не является треугольной: элемент $a_{32}=-2$ находится ниже диагонали.

Вычисление дополнений и транспонирование их матрицы дают:

$$A^{-1}=\begin{pmatrix}\frac8{23}&\frac5{23}&\frac{10}{23}&-\frac{113}{23}\\0&0&-\frac12&2\\-\frac3{23}&\frac1{23}&\frac2{23}&\frac5{23}\\0&0&0&1\end{pmatrix}.$$

Например, первая строка $AA^{-1}$ получается как первая строка $A^{-1}$ минус пять её третьих строк плюс шесть четвёртых и равна $(1,0,0,0)$. Проверка остальных строк даёт $AA^{-1}=E_4$.


## Уравнение XA равное B

Для $XA=B$ умножают **справа** на $A^{-1}$:

$$X=BA^{-1}.$$

Пусть

$$A=\begin{pmatrix}2&-3\\-1&1\end{pmatrix},\qquad B=\begin{pmatrix}-1&4\\1&-1\\-2&5\end{pmatrix}.$$

Тогда $\det A=-1$ и

$$A^{-1}=\begin{pmatrix}-1&-3\\-1&-2\end{pmatrix},\qquad X=\begin{pmatrix}-3&-5\\0&-1\\-3&-4\end{pmatrix}.$$

Проверка производится умножением $XA$ и сравнением со всеми элементами $B$.

## Три способа решения квадратной системы

Для системы

$$\begin{cases}x_1+2x_2-x_3=6,\\2x_1+5x_2-4x_3=16,\\3x_1+3x_2+2x_3=7\end{cases}$$

можно использовать метод Гаусса, формулы Крамера или обратную матрицу. Последние два способа требуют ненулевого определителя.

Покажем исключение. Вычтем из второго уравнения удвоенное первое, из третьего — утроенное первое:

$$x_2-2x_3=4,\qquad-3x_2+5x_3=-11.$$

Прибавляя к последнему утроенное $x_2-2x_3=4$, получаем $-x_3=1$. Значит, $x_3=-1$, $x_2=2$, $x_1=1$.

Проверка: $1+4+1=6$, $2+10+4=16$, $3+6-2=7$.

## Общее решение и однородная система

Для совместной неоднородной системы $AX=B$:

$$X=X_{\text{част}}+X_{\text{одн}},\qquad AX_{\text{част}}=B,\quad AX_{\text{одн}}=0.$$

Если $X_1$ и $X_2$ — два решения $AX=B$, то $A(X_1-X_2)=0$. Поэтому разность любых решений принадлежит пространству решений однородной системы.

Метод Гаусса позволяет выделить ведущие и свободные неизвестные. Если ранг $r<n$ и система совместна, свободных параметров $n-r$. Для каждого свободного параметра строят отдельный вектор фундаментальной системы решений.

## Пример системы со свободным параметром

$$\begin{cases}x_1+2x_2-3x_3+x_4=2,\\3x_1+5x_2-5x_3+4x_4=3,\\2x_1+x_2-2x_3+3x_4=1.\end{cases}$$

Исключим $x_1$: $R_2\leftarrow R_2-3R_1$, $R_3\leftarrow R_3-2R_1$. Получаем

$$-x_2+4x_3+x_4=-3,\qquad-3x_2+4x_3+x_4=-3.$$

Вычитание первого из второго даёт $x_2=0$. Тогда $4x_3+x_4=-3$, а после подстановки в первое исходное уравнение $4x_1+7x_4=-1$.

Положим $x_4=t$. Общее решение:

$$X=\begin{pmatrix}-\frac14\\0\\-\frac34\\0\end{pmatrix}+t\begin{pmatrix}-\frac74\\0\\-\frac14\\1\end{pmatrix},\qquad t\in\mathbb R.$$

Первый столбец является частным решением неоднородной системы, второй — решением соответствующей однородной. При подстановке в исходные уравнения коэффициенты при $t$ сокращаются.

## Главное

- Обратную матрицу ищут после проверки определителя.
- Для $XA=B$ решение равно $BA^{-1}$.
- Разные методы решения одной системы должны приводить к одинаковому набору неизвестных.
- Общее решение неоднородной системы складывается из частного решения и решения соответствующей однородной.
