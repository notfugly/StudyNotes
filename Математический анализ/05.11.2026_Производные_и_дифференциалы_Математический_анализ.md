# Математический анализ — 05.11.2026

**Тема:** способы дифференцирования, дифференциал и производные высших порядков.

## Правила и таблица производных

Пусть $u=u(x)$ и $v=v(x)$ дифференцируемы, $C$ — постоянная. Для частного дополнительно требуется $v\ne0$.

| Функция | Производная |
|---|---|
| $C$ | $0$ |
| $Cu$ | $Cu'$ |
| $u\pm v$ | $u'\pm v'$ |
| $uv$ | $u'v+uv'$ |
| $u/v$ | $(u'v-uv')/v^2$ |
| $f(u(x))$ | $f'(u(x))u'(x)$ |

Последнее равенство — **правило производной сложной функции**: производную внешней функции умножают на производную внутренней.

### Производные элементарных функций

Формулы применяются на участках, где соответствующие функции определены и дифференцируемы; для действительной произвольной степени $x^\alpha$ в общем случае берут $x>0$, для логарифмов $a>0$, $a\ne1$.

| Функция $f(x)$ | Производная $f'(x)$ |
|---|---|
| $x^\alpha$ | $\alpha x^{\alpha-1}$ |
| $e^x$ | $e^x$ |
| $a^x$ | $a^x\ln a$ |
| $\ln x$ | $1/x$ |
| $\log_a x$ | $1/(x\ln a)$ |
| $\sin x$ | $\cos x$ |
| $\cos x$ | $-\sin x$ |
| $\tan x$ | $1/\cos^2x$ |
| $\cot x$ | $-1/\sin^2x$ |
| $\arcsin x$ | $1/\sqrt{1-x^2}$ |
| $\arccos x$ | $-1/\sqrt{1-x^2}$ |
| $\arctan x$ | $1/(1+x^2)$ |
| $\operatorname{arcctg}x$ | $-1/(1+x^2)$ |
| $\sinh x$ | $\cosh x$ |
| $\cosh x$ | $\sinh x$ |
| $\tanh x$ | $1/\cosh^2x$ |
| $\coth x$ | $-1/\sinh^2x$ |

Для арксинуса и арккосинуса приведённые производные действуют при $|x|<1$. Гиперболические функции определяются равенствами

$$\sinh x=\frac{e^x-e^{-x}}2,\quad \cosh x=\frac{e^x+e^{-x}}2,\quad \tanh x=\frac{\sinh x}{\cosh x},\quad \coth x=\frac{\cosh x}{\sinh x}.$$

## Производная неявной функции

Если связь $x$ и $y$ задана уравнением $F(x,y)=0$, дифференцируют обе части по $x$, считая $y$ функцией $x$. Каждый раз при дифференцировании выражения с $y$ учитывают множитель $y'$. Полученное уравнение решают относительно $y'$.

**Пример.** Найти производную для $x^3+y^3-3xy=0$.

$$3x^2+3y^2y'-3(y+xy')=0.$$

После деления на $3$ и переноса слагаемых:

$$y'(y^2-x)=y-x^2,\qquad \boxed{y'=\frac{y-x^2}{y^2-x}}.$$

Формула справедлива на дифференцируемой ветви, где $y^2-x\ne0$.

## Производная параметрически заданной функции

Пусть $x=x(t)$, $y=y(t)$, где $t$ — параметр. Если в рассматриваемой точке существует дифференцируемая обратная зависимость $t=t(x)$ и $x'(t)\ne0$, правило цепочки даёт

$$\frac{dy}{dx}=\frac{dy}{dt}\frac{dt}{dx},\qquad \frac{dt}{dx}=\frac1{dx/dt}.$$

Поэтому

$$\boxed{\frac{dy}{dx}=\frac{dy/dt}{dx/dt}}.$$

Можно найти производную, не выражая $y$ непосредственно через $x$. При $x'(t)=0$ делить по этой формуле нельзя; соответствующую точку исследуют отдельно.

## Логарифмическое дифференцирование

Этот способ удобен для произведений, частных и степеней: логарифм превращает произведение в сумму, деление — в разность, а показатель степени становится множителем. Для положительной функции $y$ после логарифмирования используем $(\ln y)'=y'/y$ и затем выражаем $y'$.

**Пример.** Пусть

$$y=\frac{(x^2+2)e^x\sqrt[4]{(x-1)^3}}{(x+5)^3}.$$

При $x>1$ функция положительна, и

$$\ln y=\ln(x^2+2)+x+\frac34\ln(x-1)-3\ln(x+5).$$

Дифференцируем:

$$\frac{y'}y=\frac{2x}{x^2+2}+1+\frac3{4(x-1)}-\frac3{x+5}.$$

Следовательно,

$$\boxed{y'=\frac{(x^2+2)e^x\sqrt[4]{(x-1)^3}}{(x+5)^3}\left(\frac{2x}{x^2+2}+1+\frac3{4(x-1)}-\frac3{x+5}\right)},\quad x>1.$$

Исходная функция определена также при $x=1$, однако приведённая формула производной в этой точке не применяется.

### Показательно-степенная функция

Пусть $y=u(x)^{v(x)}$, причём $u(x)>0$. Тогда

$$\ln y=v\ln u,\qquad \frac{y'}y=v'\ln u+v\frac{u'}u.$$

Отсюда

$$\boxed{(u^v)'=u^v\left(v'\ln u+v\frac{u'}u\right)=u^v\ln u\,v'+v u^{v-1}u'}.$$

Первое слагаемое учитывает изменение показателя, второе — основания.

**Пример.** Для $y=(\sin 2x)^{x^3+1}$ на промежутках, где $\sin 2x>0$,

$$y'=(\sin 2x)^{x^3+1}\left[3x^2\ln(\sin 2x)+(x^3+1)\frac{2\cos 2x}{\sin 2x}\right].$$

## Дифференциал функции

Пусть $y=f(x)$ дифференцируема в точке $x$. Приращение аргумента $\Delta x$ вызывает приращение

$$\Delta y=f(x+\Delta x)-f(x).$$

Из определения производной следует

$$\frac{\Delta y}{\Delta x}=f'(x)+\alpha,\qquad \alpha\to0\quad(\Delta x\to0),$$

поэтому

$$\boxed{\Delta y=f'(x)\Delta x+\alpha\Delta x=f'(x)\Delta x+o(\Delta x)}.$$

**Дифференциал первого порядка** — линейная часть приращения:

$$dy=df(x)=f'(x)\Delta x.$$

Для независимой переменной $dx=\Delta x$, следовательно,

$$\boxed{dy=f'(x)\,dx},\qquad f'(x)=\frac{dy}{dx}.$$

При $f'(x)\ne0$ линейное слагаемое имеет тот же порядок малости, что и $\Delta x$, а остаток $o(\Delta x)$ — более высокого порядка. При нулевой производной дифференциал тоже определён и равен нулю, хотя называть его ненулевой главной частью нельзя.

### Геометрический смысл

Касательная к графику в точке $(x_0,f(x_0))$ имеет угловой коэффициент $f'(x_0)$ и уравнение

$$Y=f(x_0)+f'(x_0)(x-x_0).$$

При переходе от $x_0$ к $x_0+\Delta x$ **$\Delta y$** — приращение ординаты графика, а **$dy=f'(x_0)\Delta x$** — приращение ординаты касательной. При малом $\Delta x$ используют приближение

$$f(x_0+\Delta x)\approx f(x_0)+f'(x_0)\Delta x.$$

## Правила вычисления дифференциалов

При дифференцируемых $u,v$ и постоянной $C$:

| Выражение | Дифференциал |
|---|---|
| $C$ | $dC=0$ |
| $Cu$ | $d(Cu)=C\,du$ |
| $u\pm v$ | $d(u\pm v)=du\pm dv$ |
| $uv$ | $d(uv)=v\,du+u\,dv$ |
| $u/v$, $v\ne0$ | $d(u/v)=(v\,du-u\,dv)/v^2$ |

Например, правило произведения следует из

$$d(uv)=(uv)'dx=(u'v+uv')dx=v\,du+u\,dv.$$

Аналогично из таблицы производных, например, $d(\cos u)=-\sin u\,du$.

## Дифференциал сложной функции

Если $y=f(u)$, а $u=u(x)$, то по правилу цепочки

$$dy=f'(u)u'(x)\,dx.$$

Так как $du=u'(x)dx$, получаем

$$\boxed{dy=f'(u)\,du}.$$

Эта запись имеет одинаковый вид как для независимого аргумента, так и для промежуточного аргумента $u(x)$. Свойство называется **инвариантностью формы первого дифференциала**.

## Производные высших порядков

Производная $y'=f'(x)$ сама является функцией. Если она дифференцируема, её производную называют **второй производной**:

$$y''=(y')'=f''(x)=\frac{d^2y}{dx^2}.$$

Аналогично $y'''=(y'')'$, а производная $n$-го порядка определяется последовательно:

$$\boxed{y^{(n)}=\bigl(y^{(n-1)}\bigr)'}.$$

Начиная с четвёртого порядка удобно обозначение $y^{(n)}$; встречаются также римские цифры.

**Пример.** Если $y=x^3$, то

$$y'=3x^2,\qquad y''=6x,\qquad y'''=6,\qquad y^{(4)}=0.$$

## Формула Лейбница

Для произведения $y=uv$ последовательное дифференцирование даёт

$$\begin{aligned}
y'&=u'v+uv',\\
y''&=u''v+2u'v'+uv'',\\
y'''&=u'''v+3u''v'+3u'v''+uv'''.
\end{aligned}$$

Коэффициенты совпадают с биномиальными. Если существуют необходимые производные до порядка $n$, то

$$\boxed{(uv)^{(n)}=\sum_{k=0}^{n}\binom nk u^{(k)}v^{(n-k)}},\qquad \binom nk=\frac{n!}{k!(n-k)!},\quad 0!=1.$$

Здесь $u^{(0)}=u$, $v^{(0)}=v$. В частности, $\binom n0=1$, $\binom n1=n$, $\binom n2=n(n-1)/2$.

**Пример.** Найдём четвёртую производную $y=x^2e^x$. Положим $u=x^2$, $v=e^x$. Тогда

$$u'=2x,\quad u''=2,\quad u'''=u^{(4)}=0,\qquad v^{(k)}=e^x.$$

Коэффициенты для $n=4$: $1,4,6,4,1$. Поэтому

$$\begin{aligned}
y^{(4)}&=u v^{(4)}+4u'v^{(3)}+6u''v''+4u'''v'+u^{(4)}v\\
&=x^2e^x+4(2x)e^x+6(2)e^x\\
&=\boxed{e^x(x^2+8x+12)}.
\end{aligned}$$

## Высшие производные неявной функции

Для $F(x,y)=0$ сначала находят $y'$, дифференцируя исходное равенство. Затем дифференцируют выражение для $y'$, учитывая зависимость $y$ от $x$, и подставляют уже найденную первую производную; так же находят последующие.

**Пример.** Для $x^2+y^2=1$ найдём $y'''$ на ветвях, где $y\ne0$:

$$2x+2yy'=0,\qquad y'=-\frac xy.$$

Теперь

$$y''=-\frac{y-xy'}{y^2}=-\frac{y+x^2/y}{y^2}=-\frac{x^2+y^2}{y^3}=-\frac1{y^3}.$$

Ещё раз дифференцируем и подставляем $y'$:

$$y'''=3y^{-4}y'=\boxed{-\frac{3x}{y^5}}.$$

## Главное

- Для сложной функции производная равна произведению производной внешней функции на производную внутренней.
- При неявном дифференцировании $y$ считают функцией $x$; при параметрическом $dy/dx=(dy/dt)/(dx/dt)$, если знаменатель отличен от нуля.
- Логарифмическое дифференцирование упрощает произведения и степени; для $u^v$ при $u>0$ нужно учитывать изменения и основания, и показателя.
- Дифференциал $dy=f'(x)dx$ — линейная часть приращения; геометрически это приращение ординаты касательной.
- Первый дифференциал сохраняет форму при замене аргумента: для $y=f(u(x))$ имеем $dy=f'(u)du$.
- Производные высших порядков получают последовательным дифференцированием, а для произведения используют формулу Лейбница с биномиальными коэффициентами.
