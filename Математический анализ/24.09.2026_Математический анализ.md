## Монотонные последовательности

Последовательность **неубывает**, если $a_{n+1}\ge a_n$ для всех $n$, и **невозрастает**, если $a_{n+1}\le a_n$. При строгих неравенствах говорят о строгом возрастании или убывании.

Монотонность проверяют по разности $a_{n+1}-a_n$; для положительных членов удобно отношение $a_{n+1}/a_n$. Проверки первых нескольких членов недостаточно для вывода обо всех номерах.

## Теорема Вейерштрасса

**Монотонная ограниченная последовательность имеет конечный предел.** Точнее: неубывающая ограниченная сверху последовательность сходится к супремуму своих значений; невозрастающая ограниченная снизу — к инфимуму.

Пусть $(a_n)$ неубывает и $M=\sup\{a_n:n\in\mathbb N\}$. Для любого $\varepsilon>0$ найдётся $N$, для которого $a_N>M-\varepsilon$. По монотонности при $n>N$:

$$M-\varepsilon<a_N\le a_n\le M.$$

Следовательно, $|a_n-M|<\varepsilon$ и $a_n\to M$. Для убывающей последовательности доказательство аналогично с использованием инфимума.

## Метод математической индукции

Чтобы доказать утверждение $P(n)$ для всех натуральных $n$, проверяют:

1. **Базу:** $P(1)$.
2. **Переход:** из $P(k)$ выводят $P(k+1)$ для произвольного $k\ge1$.

В индуктивном переходе утверждение $P(k)$ принимается как предположение только для выбранного $k$. Нельзя заранее использовать истинность $P(k+1)$.

## Неравенство Бернулли

**При $a>-1$ и $n\in\mathbb N$:**

$$ (1+a)^n\ge1+na.$$

При $n=1$ получаем равенство. Пусть $(1+a)^k\ge1+ka$. Так как $1+a>0$, умножение сохраняет знак:

$$ (1+a)^{k+1}\ge(1+ka)(1+a)=1+(k+1)a+ka^2\ge1+(k+1)a.$$

Индуктивный переход доказан.

## Предел корня постоянного числа

**Для $a>0$: $\sqrt[n]{a}\to1$.** Если $a>1$, положим $u_n=\sqrt[n]{a}-1>0$. Неравенство Бернулли даёт

$$a=(1+u_n)^n\ge1+nu_n,\qquad0\le u_n\le\frac{a-1}{n}\to0.$$

По теореме о зажатой последовательности $u_n\to0$. При $0<a<1$ используют $b=1/a>1$ и $\sqrt[n]{a}=1/\sqrt[n]{b}\to1$. При $a=1$ результат очевиден.

## Число e

Рассмотрим

$$x_n=\left(1+\frac1n\right)^n,\qquad y_n=\left(1+\frac1n\right)^{n+1}.$$

Последовательность $x_n$ возрастает. Действительно,

$$\frac{x_{n+1}}{x_n}=\frac{n+2}{n+1}\left(1-\frac1{(n+1)^2}\right)^n\ge\frac{(n+2)(n^2+n+1)}{(n+1)^3}>1.$$

Последнее неравенство следует из того, что числитель равен $n^3+3n^2+3n+2$, а знаменатель — $n^3+3n^2+3n+1$.

Последовательность $y_n$ убывает. Для проверки:

$$\frac{y_n}{y_{n+1}}=\frac{n+1}{n+2}\left(1+\frac1{n(n+2)}\right)^{n+1}\ge\frac{n+1}{n+2}\left(1+\frac{n+1}{n(n+2)}\right)>1.$$

При этом $x_n<y_n\le y_1=4$. Следовательно, $x_n$ возрастает и ограничена сверху. По теореме Вейерштрасса существует предел, называемый **числом $e$**:

$$e=\lim_{n\to\infty}\left(1+\frac1n\right)^n.$$

Так как $y_n=x_n(1+1/n)$, последовательность $y_n$ имеет тот же предел. Отсюда:

$$\left(1+\frac1n\right)^n<e<\left(1+\frac1n\right)^{n+1}.$$

## Преобразование выражений к замечательному пределу

Если $t_n\to0$, $t_n\ne0$ и $1+t_n>0$, то выражение $(1+t_n)^{1/t_n}$ связано со вторым замечательным пределом. Для сложного показателя полезно выделить степень $1/t_n$:

$$ (1+t_n)^{s_n}=\left[(1+t_n)^{1/t_n}\right]^{t_ns_n}.$$

Сначала находят предел $t_ns_n$, затем предел всего выражения. Условие положительности основания существенно для действительных степеней.

## Главное

- Монотонности вместе с ограниченностью достаточно для сходимости.
- Индукция состоит из базы и перехода.
- Неравенство Бернулли даёт оценки степеней и корней.
- Для любого $a>0$ выполнено $\sqrt[n]{a}\to1$.
- Число $e$ определяется пределом $(1+1/n)^n$.
