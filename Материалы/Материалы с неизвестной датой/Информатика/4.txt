Теоретические сведения
Позиционные системы счисления
Позиционной называется система счисления, в которой значение цифры определяется не только её символом, но и позицией в записи числа. Каждой позиции соответствует вес, равный степени основания системы счисления.

Пусть основание системы счисления равно q, тогда число

(an an−1 … a1 a0)q

имеет числовое значение

n	∑	= ai · qi
i = 0
 
где каждая цифра удовлетворяет условию 0≤a_i<q-1.

Перевод в десятичную систему
Перевод числа из позиционной системы счисления с основанием qв десятичную выполняется путём развёртывания по степеням основания, то есть вычисления суммы произведений цифр на соответствующие степени q.

Метод является универсальным и применим к системам счисления с любым основанием.

Перевод из десятичной системы
Для перевода целого числа из десятичной системы в позиционную используется:

Метод последовательного деления на основание, при котором фиксируются остатки от деления;
Метод разложения по степеням основания, при котором определяется вклад каждой степени основания в представлении числа.
Оба метода приводят к одному и тому же результату и различаются только способом вычислений.

Примеры решения задач
Пример 1
Задача.
Перевести число (312)4 в десятичную систему счисления.

Решение

(312)4 = 3 · 42 + 1 · 41 + 2 · 40 = 48 + 4 + 2 = 54.

Программная реализация

number = input("Введите число: ")
base = int(input("Введите основание системы: "))

value = 0
for i, digit in enumerate(reversed(number)):
    value += int(digit) * (base ** i)

print("Десятичное значение:", value)
Вывод программы (пример):

Введите число: 312
Введите основание системы: 4
Десятичное значение: 54
Пример 2
Задача.
Перевести десятичное число 45 в систему счисления с основанием 3.

Решение

Последовательное деление:

45 ÷ 3 = 15, остаток 0
15 ÷ 3 = 5, остаток 0
5 ÷ 3 = 1, остаток 2
1 ÷ 3 = 0, остаток 1

Результат: (45)10 = (1200)3.

Программная реализация

number = int(input("Введите десятичное число: "))
base = int(input("Введите основание системы: "))

if number == 0:
    result = "0"
else:
    digits = []
    n = number
    while n > 0:
        digits.append(str(n % base))
        n //= base
    result = ''.join(reversed(digits))

print("Результат перевода:", result)

Введите основание системы: 3
Результат перевода: 1200

Решение

(2A)16 = 2 · 161 + 10 · 160 = 32 + 10 = 42.

Пример 4
Задача.
Реализовать универсальные функции перевода чисел между позиционными системами счисления с проверкой корректности входных данных.

Программная реализация

def to_decimal(number: str, base: int, alphabet: str = "0123456789ABCDEF") -> int:
    if not (2 <= base <= len(alphabet)):
        raise ValueError("Недопустимое основание системы.")

    value = 0
    for i, ch in enumerate(reversed(number.upper())):
        if ch not in alphabet:
            raise ValueError("Недопустимый символ.")
        digit = alphabet.index(ch)
        if digit >= base:
            raise ValueError("Цифра не принадлежит данной системе счисления.")
        value += digit * (base ** i)
    return value


def from_decimal(number: int, base: int, alphabet: str = "0123456789ABCDEF") -> str:
    if not (2 <= base <= len(alphabet)):
        raise ValueError("Недопустимое основание системы.")
    if number == 0:
        return "0"

    digits = []
    n = number
    while n > 0:
        digits.append(alphabet[n % base])
        n //= base
    return ''.join(reversed(digits))


n = int(input("Введите десятичное число: "))
b = int(input("Введите основание системы: "))

converted = from_decimal(n, b)
restored = to_decimal(converted, b)

print("Результат перевода:", converted)
print("Проверка обратным переводом:", restored)

Проверка обратным переводом: 42
