Тема: Теория информации. Методы измерения количества информации. Формула Хартли. Общая энтропия по Шеннону.
Цель работы
Закрепить теоретические положения теории информации и сформировать навыки количественной оценки информации с использованием формулы Хартли и энтропии по Шеннону.

 
Теоретические сведения
В теории информации информация рассматривается как количественная характеристика уменьшения неопределённости при получении сообщения. Количественные меры информации строятся на логарифмических зависимостях, что обеспечивает согласование с принципом аддитивности: при объединении независимых сообщений их информационные количества суммируются.

Основной единицей измерения информации является бит. Один бит соответствует выбору из двух равновероятных альтернатив. Для практических расчётов также используются производные единицы: байт (8 бит), килобайт, мегабайт и т. д.

Если источник сообщений формирует N равновероятных сообщений, количество информации в одном сообщении определяется формулой Хартли: I=log2N
. Если сообщение состоит из k
 независимых символов алфавита мощности N
, информационный объём сообщения равен Iсообщ=k⋅log2N
.

Когда сообщения возникают с различными вероятностями pi
, применяется энтропия Шеннона, определяющая среднее количество информации, приходящееся на одно сообщение источника: H=−∑ni=1pilog2pi
. Энтропия достигает максимума при равновероятном распределении вероятностей и уменьшается по мере повышения предсказуемости источника. Для источника из n
 возможных сообщений максимальная энтропия равна Hmax=log2n
.

 
Примеры решения задач
Пример 1
Задача.
Источник информации может выдавать 32 различных равновероятных сообщения. Определить количество информации по формуле Хартли.

Решение.
Для равновероятных сообщений количество информации определяется формулой Хартли:

I = log2 N.

Подставим значение:

I = log2 32 = 5.

Программная реализация:

import math

N = 32
I = math.log2(N)
print(I)
Вывод программы:

5.0
Интерпретация результата.
Для однозначного выбора одного сообщения из 32 равновероятных требуется 5 бит информации.

Пример 2
Задача.
Источник формирует 8 равновероятных сообщений. Вычислить энтропию источника по Шеннону и сравнить её с количеством информации по Хартли.

Решение.
Вероятность каждого сообщения:

pi = 1/8.

Энтропия Шеннона:

H = −∑i=18 pi log2 pi.

Подставим значения:

H = −8 · 1/8 · log2(1/8) = −log2(1/8) = log2 8 = 3.

Программная реализация:

import math

p = [1/8] * 8
H = -sum(pi * math.log2(pi) for pi in p)
print(H)
Вывод программы:

3.0
Интерпретация результата.
Энтропия равна 3 битам и совпадает с количеством информации по Хартли, что соответствует максимальной неопределённости источника.

Пример 3
Задача.
Источник формирует сообщения с вероятностями

p = {0.5, 0.25, 0.125, 0.125}.

Определить энтропию источника по Шеннону.

Решение.
Используем формулу Шеннона:

H = −∑i=14 pi log2 pi.

Вычислим по слагаемым:

H = −(0.5 log2 0.5 + 0.25 log2 0.25 + 0.125 log2 0.125 + 0.125 log2 0.125).

Зная, что:

log2 0.5 = −1, log2 0.25 = −2, log2 0.125 = −3,

получаем:

H = −(0.5·(−1) + 0.25·(−2) + 0.125·(−3) + 0.125·(−3)) = 1.75.

Программная реализация:

import math

p = [0.5, 0.25, 0.125, 0.125]
H = -sum(pi * math.log2(pi) for pi in p)
print(H)
Вывод программы:

1.75
Интерпретация результата.
Энтропия меньше максимального значения для четырёх сообщений, что указывает на наличие предсказуемости в источнике информации.

Пример 4
Задача.
Для источника, состоящего из четырёх сообщений, сравнить энтропию при равномерном и неравномерном распределении вероятностей.

Решение.
Рассмотрим два источника информации с одинаковым числом сообщений:

равномерное распределение вероятностей;
неравномерное распределение вероятностей.
Энтропия Шеннона вычисляется по формуле:

H = −∑i=1n pi log2 pi.

1) Равномерное распределение

p = {0.25, 0.25, 0.25, 0.25}.

H = −4 · 0.25 · log2(0.25).

log2(0.25) = −2.

H = 2.

2) Неравномерное распределение

p = {0.7, 0.1, 0.1, 0.1}.

H = −(0.7 log2 0.7 + 3·0.1 log2 0.1).

log2(0.7) ≈ −0.514573, log2(0.1) ≈ −3.321928.

H ≈ 1.356779.

Программная реализация:

import math

# Равномерное распределение
p_uniform = [0.25, 0.25, 0.25, 0.25]
H_uniform = -sum(pi * math.log2(pi) for pi in p_uniform)

# Неравномерное распределение
p_non_uniform = [0.7, 0.1, 0.1, 0.1]
H_non_uniform = -sum(pi * math.log2(pi) for pi in p_non_uniform)

print("Энтропия при равномерном распределении:", H_uniform)
print("Энтропия при неравномерном распределении:", H_non_uniform)
Вывод программы:

Энтропия при равномерном распределении: 2.0
Энтропия при неравномерном распределении: 1.3567796494470395
Интерпретация результата.
Энтропия источника с равномерным распределением вероятностей максимальна. При переходе к неравномерному распределению энтропия уменьшается, что отражает рост предсказуемости сообщений источника.
