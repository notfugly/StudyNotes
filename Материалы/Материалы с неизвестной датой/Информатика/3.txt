Теоретические сведения
Ошибки при передаче информации
При передаче двоичных данных по каналам связи возможны искажения отдельных битов. Наиболее типичной моделью является битовая ошибка, при которой значение бита меняется с 0 на 1 или с 1 на 0.

Для повышения надёжности применяются коды с избыточностью, позволяющие:

обнаруживать факт искажения;
в некоторых случаях определять позицию ошибки;
исправлять ошибку без повторной передачи.
Расстояние Хэмминга и различимость кодов
Расстояние Хэмминга между двумя двоичными словами одинаковой длины — это число позиций, в которых биты различаются.

Минимальное расстояние Хэмминга dmin множества кодовых слов определяет возможности кода:

обнаружение до dmin − 1 ошибок;
исправление до ⌊(dmin − 1) / 2⌋ ошибок.
Бит чётности
Бит чётности — дополнительный контрольный бит, добавляемый к сообщению.

Для чётного контроля выбирают такой бит p, чтобы общее число единиц в кодовом слове было чётным.

Бит чётности позволяет обнаруживать все ошибки нечётной кратности (в частности, одиночную), но не позволяет определить позицию ошибки и не обнаруживает ошибки чётной кратности.

Троирование бит и правило большинства
Троирование — простейший избыточный код: каждый бит заменяется тройкой одинаковых битов:

0 → 000
1 → 111

Декодирование выполняется по правилу большинства: в тройке выбирается значение, встречающееся не менее двух раз. Такой код позволяет исправлять одиночную ошибку в каждой тройке.

Код Хэмминга (7,4)
Код Хэмминга (7,4) преобразует 4 информационных бита в 7-битное слово, добавляя 3 контрольных бита. Контрольные биты размещаются в позициях 1, 2 и 4, а информационные — в позициях 3, 5, 6 и 7.

Позиции:

1 — p1, 2 — p2, 3 — d1, 4 — p4, 5 — d2, 6 — d3, 7 — d4

Синдром ошибки вычисляется проверкой контрольных соотношений и даёт номер ошибочного разряда (если синдром равен 0, ошибки не обнаружено). Код Хэмминга (7,4) исправляет одну одиночную ошибку.

Примеры решения задач
Пример 1
Задача.
Для сообщения 110101 сформировать кодовое слово с чётным битом чётности и определить, обнаруживается ли ошибка при искажении одного бита.

Решение

Сообщение:
110101

Число единиц равно 4, оно чётное, значит бит чётности:

p = 0.

Кодовое слово:

1101010.

Если в передаче изменился один бит, чётность станет нечётной, следовательно ошибка будет обнаружена.

Программная реализация

message = "110101"
ones = message.count("1")
p = ones % 2
codeword = message + str(p)

received = list(codeword)
received[2] = "0" if received[2] == "1" else "1"   # моделирование одиночной ошибки
received = "".join(received)

check = received.count("1") % 2

print("Сообщение:", message)
print("Кодовое слово:", codeword)
print("Принято:", received)
print("Контроль чётности:", check)
print("Ошибка обнаружена" if check == 1 else "Ошибка не обнаружена")
Вывод программы (пример):

Сообщение: 110101
Кодовое слово: 1101010
Принято: 1111010
Контроль чётности: 1
Ошибка обнаружена
Интерпретация результата.
Бит чётности позволяет обнаружить одиночную ошибку, но не даёт информации о её позиции.

Пример 2
Задача.
Вычислить расстояние Хэмминга между словами 1010110 и 1000011 и интерпретировать результат.

Решение

Сравним побитно:

1010110
1000011

Различия наблюдаются в позициях 3, 5 и 7, следовательно:

d = 3.

Программная реализация

a = "1010110"
b = "1000011"

d = sum(x != y for x, y in zip(a, b))

print("Слово 1:", a)
print("Слово 2:", b)
print("Расстояние Хэмминга:", d)
Вывод программы:

Слово 1: 1010110
Слово 2: 1000011
Расстояние Хэмминга: 3
Интерпретация результата.
Значение расстояния Хэмминга характеризует различимость кодовых слов: чем больше расстояние, тем выше потенциальная устойчивость к ошибкам при корректно построенном коде.

Пример 3
Задача.
Закодировать сообщение 1010 методом троирования, смоделировать одиночную ошибку в одной тройке и восстановить исходное сообщение правилом большинства.

Решение

Кодирование:
1 → 111, 0 → 000.

Сообщение:
1010 ⇒ 111 000 111 000.

Искажён один бит, например в первой тройке:
111 ⇒ 101.

По правилу большинства 101 ⇒ 1. Аналогично декодируются остальные тройки, восстановление даёт исходное сообщение 1010.

Программная реализация

message = "1010"
encoded = ''.join("111" if b == "1" else "000" for b in message)

# ошибка в первой тройке: меняем второй бит
broken = list(encoded)
broken[1] = "0" if broken[1] == "1" else "1"
broken = "".join(broken)

def majority(triple: str) -> str:
    return "1" if triple.count("1") >= 2 else "0"

decoded = ''.join(majority(broken[i:i+3]) for i in range(0, len(broken), 3))

print("Исходное сообщение:", message)
print("Троированный код:", encoded)
print("Принято с ошибкой:", broken)
print("Декодировано:", decoded)
Вывод программы (пример):

Исходное сообщение: 1010
Троированный код: 111000111000
Принято с ошибкой: 101000111000
Декодировано: 1010
Интерпретация результата.
Троирование повышает надёжность и позволяет исправлять одиночную ошибку в каждой тройке, но увеличивает объём данных втрое.

Пример 4
Задача.
Закодировать информационное слово 1011 кодом Хэмминга (7,4). Смоделировать одиночную ошибку в позиции 5 и выполнить исправление по синдрому.

Решение

Размещение битов:

d1 = 1 в позицию 3
d2 = 0 в позицию 5
d3 = 1 в позицию 6
d4 = 1 в позицию 7

Позиции: [p1, p2, d1, p4, d2, d3, d4].

Контрольные биты для чётного контроля:

p1 контролирует позиции 1, 3, 5, 7
p2 контролирует позиции 2, 3, 6, 7
p4 контролирует позиции 4, 5, 6, 7

Получаем кодовое слово (после вычисления p1, p2, p4):

0110011.

Ошибка в позиции 5 меняет бит:

0110011 ⇒ 0110111.

Синдром указывает номер ошибочного разряда 5, после инверсии пятого бита восстанавливается исходное кодовое слово.

Программная реализация на Python

def hamming74_encode(data_bits: str) -> str:
    d1, d2, d3, d4 = (int(x) for x in data_bits)
    p1 = d1 ^ d2 ^ d4
    p2 = d1 ^ d3 ^ d4
    p4 = d2 ^ d3 ^ d4
    code = [p1, p2, d1, p4, d2, d3, d4]
    return ''.join(str(x) for x in code)

def hamming74_syndrome(code_bits: str) -> int:
    b = [int(x) for x in code_bits]
    s1 = b[0] ^ b[2] ^ b[4] ^ b[6]
    s2 = b[1] ^ b[2] ^ b[5] ^ b[6]
    s4 = b[3] ^ b[4] ^ b[5] ^ b[6]
    return s1 * 1 + s2 * 2 + s4 * 4

def hamming74_correct(code_bits: str) -> str:
    b = [int(x) for x in code_bits]
    pos = hamming74_syndrome(code_bits)
    if pos != 0:
        b[pos - 1] ^= 1
    return ''.join(str(x) for x in b)

data = "1011"
code = hamming74_encode(data)

broken = list(code)
broken[4] = "0" if broken[4] == "1" else "1"   # ошибка в позиции 5
broken = ''.join(broken)

syn = hamming74_syndrome(broken)
fixed = hamming74_correct(broken)

print("Данные:", data)
print("Код Хэмминга:", code)
print("Принято с ошибкой:", broken)
print("Синдром:", syn)
print("Исправлено:", fixed)
Вывод программы (пример):

Данные: 1011
Код Хэмминга: 0110011
Принято с ошибкой: 0110111
Синдром: 5
Исправлено: 0110011
Интерпретация результата.
Код Хэмминга (7,4) позволяет определить позицию одиночной ошибки и восстановить корректное кодовое слово без повторной передачи.
