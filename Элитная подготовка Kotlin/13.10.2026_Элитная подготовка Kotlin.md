## Null-безопасность

`null` обозначает отсутствие значения. Тип `String` не допускает `null`, тип `String?` допускает строку или `null`.

```kotlin
var name: String? = "James"
println(name?.length)       // 5
name = null
println(name?.length)       // null
println(name?.length ?: -1) // -1
```

**Безопасный вызов `?.`** обращается к свойству или методу только при ненулевом получателе; иначе результат — `null`. **Оператор Элвиса `?:`** возвращает правую часть, если результат слева равен `null`; правую часть вычисляют только в этом случае.

**Утверждение `!!`** превращает nullable-значение в ненулевое, но выбрасывает исключение при `null`. Оно не заменяет проверку.

В исходнике `name!!.length` выполняется, пока `name` содержит `"James"`, и даёт `5`. После `name = null` такое обращение завершилось бы `NullPointerException`. Сам оператор — `!!`; запись `name!!.length` объединяет утверждение ненулевого значения и обычный доступ через точку.

Выражение `name?.length` имеет nullable-тип `Int?`. После присваивания `null` строка из урока `println(name?.length ?: "New James")` печатает `New James`. Если имя задано, она печатает его длину. Оператор `?:` срабатывает именно на `null`: длина пустой строки равна `0` и сама по себе не вызывает подстановку.

```kotlin
val dataFromServer: String? = "123"
dataFromServer?.let { value -> println(value.length) }
if (dataFromServer != null) {
    println(dataFromServer.length)
}
```

После допустимой проверки компилятор может сузить тип. `null` отличается от пустой строки `""`: пустая строка существует и имеет длину 0.

## Список, множество, отображение и массив

| Структура | Создание | Особенности |
|---|---|---|
| `List` | `listOf(...)` | упорядоченные элементы, повторы разрешены |
| `Set` | `setOf(...)` | уникальные элементы, основная операция — принадлежность |
| `Map` | `mapOf(key to value)` | соответствие ключей значениям |
| `Array` | `arrayOf(...)` | фиксированная длина, элементы можно заменять |

```kotlin
val cities = listOf("Москва", "Казань", "Саратов", "Сочи", "Саратов")
println(cities.size)          // 5
println(cities[2])            // Саратов
println(cities.indexOf("Сочи")) // 3
println(cities.indexOf("Пермь")) // -1
println(cities.getOrNull(100)) // null
println(cities.toSet())       // уникальные элементы
println(cities.distinct())    // список уникальных элементов

val capitals = mapOf("Россия" to "Москва", "Великобритания" to "Лондон")
println(capitals["Россия"])
println(capitals["Неизвестная страна"]) // null
println(capitals.keys)
println(capitals.values)
```

Индексы списка начинаются с 0. Обычный доступ по несуществующему индексу вызывает исключение; `getOrNull` позволяет обработать отсутствие. У множества нет обычного индексного доступа `set[index]`: оно предназначено для уникальности и проверки `value in set`.

`size` считает все элементы, включая повторы. `indexOf(value)` возвращает индекс первого совпадения либо `-1`, если значения нет. Для приведённого списка `distinct()` даст `[Москва, Казань, Саратов, Сочи]`, сохранив порядок первого появления городов.

```kotlin
val uniqueCities = setOf("Москва", "Казань", "Сочи", "Москва", "Сочи")
println(uniqueCities.size)       // 3
println("Казань" in uniqueCities) // true
```

Множество устраняет повторы уже при создании. `distinct()` возвращает `List`, а `toSet()` — `Set`; выбор зависит от дальнейших операций.

Ключи `Map` уникальны. При повторении ключа в `mapOf` сохраняется **последнее** переданное значение. Для ключа важно стабильное поведение `equals` и `hashCode`: изменение значимых для них свойств может нарушить поиск в хеш-структуре.

`List`, `Set`, `Map` дают интерфейсы чтения; это само по себе не является гарантией глубокой неизменяемости всех объектов внутри коллекции.

## Изменяемые коллекции

```kotlin
val people = mutableListOf("Борис", "Анна", "Никита")
people.add("Пётр")
people.add(0, "Евгений")
people.add(2, "Светлана")
people.removeAt(2)
people.remove("Анна")
people.clear()
```

`add(index, value)` вставляет элемент, сдвигая последующие; `removeAt(index)` удаляет по индексу, `remove(value)` — по значению. Для вставки допустимы индексы `0..size`, для чтения и удаления — `0 until size`.

В исходнике для вставки в начало и конец также используются `addFirst` и `addLast`. Для списка на JVM эти методы Java `List` доступны начиная с JDK 21; варианты `add(0, value)` и `add(value)` из примера выше позволяют выполнить те же действия на более старом JDK. См. [документацию Java List](https://docs.oracle.com/en/java/javase/21/docs/api/java.base/java/util/List.html#addFirst(E)).

После вставки или удаления индексы следующих элементов меняются. Например, `removeAt(2)` удаляет элемент, находящийся на третьем месте **в момент вызова**, а не обязательно третий элемент исходного списка. `remove(value)` удаляет первое совпадение; повторяющиеся значения не запрещены.

`mutableSetOf` и `mutableMapOf` создают изменяемые множество и отображение. Объявление `val` запрещает присвоить переменной другую коллекцию, но не запрещает менять содержимое изменяемой коллекции.

## Фильтрация, преобразование и поиск

```kotlin
val words = listOf("Kotlin", "is", "a", "language")
val longWords = words.filter { it.length > 5 }
val lengths = words.map { it.length }
val upper = words.map { it.uppercase() }

println(words.any { it == "is" })  // true
println(words.all { it.length > 5 }) // false
println(words.none { it == "is?" }) // true
println(words.count { it == "is" }) // 1
```

`filter` сохраняет подходящие элементы; `map` вычисляет новое значение для каждого. Здесь они возвращают новые списки и не заменяют содержимое `words`. `it` — неявное имя единственного параметра лямбды.

`any` отвечает, существует ли подходящий элемент; `all` — подходят ли все; `none` — отсутствуют ли подходящие; `count` — сколько их. Это разные вопросы, поэтому нельзя подменять один метод другим.

Для списка из репозитория `listOf("Helo", "World", "my", "name", "is", "Nikita")` выражение `filter { it.length > 5 }` возвращает только `[Nikita]`. Результаты `any { it == "is" }`, `all { it == "is" }`, `none { it == "!is" }` и `count { it == "is" }` — соответственно `true`, `false`, `true` и `1`.

Строка `"!is"` означает буквальный текст с восклицательным знаком. Это не логическое отрицание условия: отрицание записывается как `it != "is"` или `!(it == "is")`.

## Сортировка, агрегация и части списка

```kotlin
val digits = listOf(5, 6, 2, 6, 9)
println(digits.sorted())
println(digits.sortedDescending())
println(words.sortedBy { it.length })
println(words.sortedByDescending { it.length })
println(digits.sum())
println(digits.average())
println(digits.minOrNull())
println(digits.maxOrNull())

println(digits.take(3))      // [5, 6, 2]
println(digits.takeLast(2))  // [6, 9]
println(digits.drop(3))      // [6, 9]
println(digits.dropLast(2))  // [5, 6, 2]
println(digits.chunked(2))  // [[5, 6], [2, 6], [9]]
```

`sorted` создаёт отсортированный список. Для строк обычная сортировка следует естественному сравнению строк; `sortedBy` позволяет явно задать ключ.

`take(n)` берёт первые **n элементов**, `drop(n)` пропускает первые n. `chunked(n)` делит на группы **размером не более n**, а не на n равных групп; последняя может быть короче. При `n`, большем размера списка, получается одна группа.

`takeLast(n)` берёт последние n элементов, `dropLast(n)` исключает их. В этих операциях сохраняется исходный порядок выбранных элементов. Для `take` и `drop` число n должно быть неотрицательным, для `chunked` размер группы должен быть положительным.

### Разбор числового примера из репозитория

Для `val digits = listOf(5, 6, 2, 6, 9, 2, 132, 9, 210)`:

| Выражение | Результат |
| --- | --- |
| `digits.sorted()` | `[2, 2, 5, 6, 6, 9, 9, 132, 210]` |
| `digits.sortedDescending()` | `[210, 132, 9, 9, 6, 6, 5, 2, 2]` |
| `digits.sum()` | `381` |
| `digits.min()` | `2` |
| `digits.max()` | `210` |
| `digits.average()` | примерно `42.333333333333336` |
| `digits.take(4)` | `[5, 6, 2, 6]` |
| `digits.takeLast(4)` | `[2, 132, 9, 210]` |
| `digits.drop(4)` | `[9, 2, 132, 9, 210]` |
| `digits.dropLast(3)` | `[5, 6, 2, 6, 9, 2]` |
| `digits.chunked(2)` | `[[5, 6], [2, 6], [9, 2], [132, 9], [210]]` |

В исходнике вызваны `min()` и `max()`: на пустой коллекции они выбрасывают исключение. Использованные выше `minOrNull()` и `maxOrNull()` возвращают `null`. Для пустого списка чисел `sum()` даёт `0`, а `average()` — `NaN`. Сортировка и выбор частей создают результат, оставляя исходный список прежним. См. [агрегацию](https://kotlinlang.org/docs/collection-aggregate.html) и [выбор частей коллекции](https://kotlinlang.org/docs/collection-parts.html).

## Функции, параметры и выражения

```kotlin
fun f1() { println("F1()") }
fun f1Short() = println("F1()")
fun greeting(name: String = "Default"): String = "Hello, $name"

val x = 50
val y = when {
    x >= 100 -> 200
    x >= 10 -> 20
    x >= 1 -> 2
    else -> 0
}
val z = if (x > 0) x else 0
```

`if` и `when` могут возвращать значение. В `when` выполняется первая подходящая ветвь; для `x=50` значение `y` равно 20. Порядок условий поэтому существенен.

## Расширения, infix и vararg

**Функция расширения** вызывается как метод получателя:

```kotlin
fun String.hello(): String = "Hello, $this"
infix fun Int.myPlus(other: Int): Int = this + other

println("Bob".hello())
println(4.myPlus(3))
println(4 myPlus 3)
```

`this` обозначает получателя. Расширение не изменяет определение исходного класса. Для инфиксного вызова функция должна быть членом или расширением с одним подходящим параметром.

```kotlin
fun printStrings(vararg strings: String) {
    strings.forEach { println(it) }
}

printStrings("abc", "def", "bob")
printStrings(*arrayOf("abc", "def", "bob"))
```

`vararg` принимает переменное число аргументов. Оператор `*` разворачивает элементы массива в такие аргументы.

## Функции как значения и замыкания

Тип `(Int, Int) -> Int` обозначает функцию с двумя целочисленными параметрами и целочисленным результатом:

```kotlin
val sum = { a: Int, b: Int -> a + b }
println(sum(1, 2))

fun counter(startNum: Int = 0): (Int, Int) -> Unit {
    var current = startNum
    return fun(a: Int, b: Int) {
        println(current++)
    }
}

val next = counter(10)
next(1, 2) // 10
next(3, 4) // 11
```

Возвращённая функция удерживает переменную `current` — это **замыкание**. В данном примере параметры `a` и `b` не участвуют в вычислении: функция печатает счётчик, а не сумму аргументов. Два отдельных вызова `counter` создают независимые состояния.

## Git и история изменений

**Git** — система управления версиями; **GitHub** — сервис размещения репозиториев. Репозиторий хранит историю изменений, **коммит** фиксирует выбранное состояние проекта с сообщением.

Локальный коммит сохраняет изменения в истории на компьютере. **Push** передаёт коммиты в удалённый репозиторий. Сохранение файла, создание коммита и отправка на сервер — три разных действия.

Практический цикл: внести связанное изменение → проверить его → выбрать файлы для коммита → написать понятное сообщение → создать коммит → при необходимости отправить. Переход к старой ревизии позволяет посмотреть прежнее состояние; незакоммиченные изменения перед этим требуют отдельного внимания.

Скачивание ZIP даёт снимок файлов; клонирование репозитория позволяет работать также с его историей.

## Класс, объект и конструктор

**Класс** задаёт свойства и поведение, **объект** — конкретный экземпляр класса. Создание двух экземпляров обычного класса даёт два самостоятельных объекта, даже если значения их свойств одинаковы.

```kotlin
class Car(
    val brand: String,
    val wheels: Int = 4,
    val engine: Double
) {
    override fun toString(): String = "$brand: $wheels колеса, $engine"
}

val car = Car("Волга", engine = 4.4)
println(car)
```

Параметры конструктора с `val` или `var` становятся свойствами. Именованный аргумент позволяет оставить `wheels` по умолчанию. `toString()` определяет строковое представление объекта; его обычный вывод не следует понимать как гарантированный адрес в памяти.

### Изменяемое свойство, метод и блок init

В `Lesson 3.kt` класс `Car` объявлен с `var brand`, `val wheel: Int = 4` и `val power: Double`. Поэтому `Car("Volga", power = 4.4)` создаёт объект с четырьмя колёсами, после чего его марку можно заменить: `car.brand = "Маруся"`. Изменять `wheel` или `power` присваиванием снаружи нельзя.

Метод — функция, принадлежащая классу. В уроке `ride()` печатает марку текущей машины; после изменения `brand` он использует уже новое значение.

```kotlin
class LessonCar(var brand: String) {
    init {
        val newCar = true
        println("Создана машина $brand: $newCar")
    }

    fun ride() = println("Ride $brand")
}
```

`init` выполняется при создании **каждого** экземпляра. Объявленная внутри него переменная `newCar` локальна для блока и не становится свойством: обратиться к `car.newCar` нельзя. Чтобы хранить признак в объекте, его объявляют как свойство класса. Подробности — [классы и инициализация](https://kotlinlang.org/docs/classes.html).

## Инкапсуляция и доступ к свойствам

**Инкапсуляция** объединяет данные и операции над ними, позволяя контролировать изменение состояния. `public` доступен снаружи и используется по умолчанию; `private` ограничивает доступ соответствующей областью.

```kotlin
class Person(var name: String, age: Int) {
    var age: Int = age
        private set

    fun changeAge(age: Int) {
        require(age >= 0)
        this.age = age
    }
}
```

`private set` разрешает чтение снаружи и изменение внутри класса. `this.age` — свойство объекта; `age` в параметрах метода — переданное значение. В Kotlin пользовательский `set(value)` вызывается и при обычном присваивании свойству, если сеттер доступен.

В репозитории показан и вариант с обычными методами `getAge()` и `setAge(age: Int)` вокруг свойства `private var age`. Вызов `person.getAge()` читает возраст, а `person.setAge(29)` меняет его. Внутри такого сеттера `this.age = age` присваивает свойству объекта значение параметра. Само наличие метода `setAge` не проверяет возраст: в исходнике проверок нет; `require` в примере выше добавляет такое ограничение.

Свойство `lastName` в исходнике объявлено как `var` с `private set`: его можно прочитать снаружи, но присвоить новое значение можно только из класса. Простое выражение `person.lastName` ничего не печатает; для вывода нужен `println(person.lastName)`.

## Наследование и переопределение

Обычные классы и методы Kotlin закрыты для наследования или переопределения по умолчанию. `open` разрешает расширение, `override` обозначает переопределение.

```kotlin
open class Animal(val name: String) {
    open fun sound(): String = "звук"
}

class Dog(name: String) : Animal(name) {
    override fun sound(): String = "гав"
}

class Cat(name: String) : Animal(name) {
    override fun sound(): String = "мяу"
}
```

Наследник получает общее свойство `name`, но задаёт собственное поведение `sound`. Объект класса и наследник класса — разные понятия: `Dog("Рыжик")` является объектом, а `Dog` — классом-наследником `Animal`.

В исходнике у `Animal` три свойства: `name`, `age` и `type`. Классы `Dog`, `Cat` и `Bober` передают аргументы конструктору родителя через `: Animal(name, age, type)` и переопределяют `sound()`. Их методы печатают соответственно `Гав-гав`, `Мяу-мяу` и `Издает звуки`. Параметр конструктора наследника без `val` или `var` сам по себе не создаёт новое свойство; доступное `name` здесь унаследовано от `Animal`.

## Главное

- Nullable-типы требуют явной обработки отсутствующего значения.
- Коллекции различаются порядком, уникальностью и способом доступа.
- `filter`, `map`, сортировка и агрегация решают разные задачи.
- Функции можно передавать и возвращать; замыкание сохраняет доступ к внешнему состоянию.
- Коммит локален, push передаёт историю на удалённый сервер.
- Класс описывает объекты, конструктор задаёт их начальное состояние.
- Инкапсуляция контролирует изменения, наследование позволяет уточнять общее поведение.
- `indexOf` возвращает `-1` при отсутствии элемента, а `getOrNull` — `null` при недопустимом индексе.
- `min` и `max` требуют непустую коллекцию; варианты `OrNull` позволяют обработать пустую.
- Локальная переменная в `init` не становится свойством объекта; чтение свойства само по себе не выводит его в консоль.
