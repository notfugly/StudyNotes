## Структура программы и комментарии

```kotlin
import java.text.DecimalFormat

fun main() {
    // Точка входа в программу
}
```

- `import` позволяет обращаться к классу по короткому имени. `DecimalFormat` предназначен для форматирования чисел; его импорт нужен, если класс используется в программе.
- `fun` объявляет функцию. `main()` — точка входа: выполнение программы начинается с её тела.
- `{ ... }` ограничивают тело функции или другого блока кода.
- `//` начинает однострочный комментарий.
- `/* ... */` ограничивает многострочный комментарий. Kotlin поддерживает вложенные многострочные комментарии, поэтому внутренние учебные комментарии не закрывают внешний блок преждевременно.
- Функции `sum1`, `sum2`, `sum3`, `create` объявлены вне `main()`. Это функции верхнего уровня; их можно вызывать из `main()`, даже если объявления расположены ниже.

## Вывод в консоль

```kotlin
print("Hello World! 1")
println("Hello World! 2")
print("Hello World! 3")
println()
```

`print()` выводит значение без перевода строки. `println()` выводит значение и переводит строку; без аргумента просто переводит строку. Перевод строки следует отличать от отступа, который создаётся пробелами или табуляцией.

Эти четыре вызова дадут:

```text
Hello World! 1Hello World! 2
Hello World! 3
```

`println("РАЗДЕЛ ПЕРЕМЕННЫЕ")` затем выводит заголовок раздела.

## Переменные: val и var

```kotlin
val a = 1
var b = 2
b = 2
println(a)
println(b)
```

`val` запрещает повторное присваивание переменной. `var` разрешает менять её значение. В примере `b = 2` допустимо, но фактически ничего не меняет, поскольку `b` уже равна `2`.

Вызовы `println(a)` и `println(b)` выводят `1` и `2` на отдельных строках.

**Ключевое различие:** `val` не гарантирует неизменность самого объекта. Например, массив, объявленный через `val`, всё равно позволяет изменять элементы.

### Выведение типа и явное указание

```kotlin
val c = 5          // Int: тип выведен из значения
val d: Long = 10   // Long: тип указан явно
val c1 = 10L      // Long: суффикс L
val e: Float = 4.6F
```

После имени переменной можно поставить `: Тип`. При выведении типа компилятор определяет его автоматически; это не означает, что тип потом можно произвольно менять.

| Тип | Что хранит | Пример |
| --- | --- | --- |
| `Int` | 32-битное целое число | `5` |
| `Long` | 64-битное целое число | `10L` |
| `Float` | 32-битное число с плавающей точкой | `4.6F` |
| `Double` | 64-битное число с плавающей точкой | `4.6` |
| `Boolean` | Логическое значение | `true`, `false` |
| `String` | Строку | `"Hello"` |
| `Char` | Один символ | `'3'` |

Без суффикса `F` дробный литерал обычно имеет тип `Double`. Числа с плавающей точкой могут храниться приближённо.

```kotlin
var f = true
f = false
val char: Char = '3'
```

В переменной `f` логическое значение меняется с `true` на `false`. Переменная `char` хранит символ цифры, а не число `3`: одинарные кавычки обозначают `Char`, двойные — `String`.

## Арифметика

При `a = 1`, `b = 2`:

| Выражение | Значение | Смысл |
| --- | --- | --- |
| `a + b` | `3` | Сложение |
| `a - b` | `-1` | Вычитание |
| `a * b` | `2` | Умножение |
| `a / b` | `0` | Целочисленное деление |
| `a % b` | `1` | Остаток от деления |

При делении целых чисел дробная часть отбрасывается: `1 / 2` даёт `0`. В `a / e` один операнд имеет тип `Float`, поэтому результат тоже дробный, примерно `0.2173913`.

```kotlin
var counter = 0
counter += 5  // Теперь 5
counter--     // Теперь 4
counter++     // Теперь 5
println(counter)
```

`+=` прибавляет значение с присваиванием; `++` увеличивает на единицу, `--` уменьшает. Итоговый вывод — `5`.

## Преобразования типов

```kotlin
var i: Int = 100
val l = i.toDouble()
val str1 = "123"
println(str1.toDouble())
```

`toDouble()` преобразует значение в `Double`: `l` будет `100.0`, а строка `"123"` превратится в `123.0`. Исходная переменная `i` остаётся целым числом. В общем случае используются методы `toInt()`, `toLong()`, `toFloat()` и другие.

Если строка не содержит корректное число, `toDouble()` или `toInt()` выбросит исключение. Для обработки некорректного ввода существуют `toDoubleOrNull()` и `toIntOrNull()`, возвращающие `null` при неудаче.

## Строки

### Склеивание и шаблоны

```kotlin
val name = "Nikita"
val age = 24

println("Меня зовут " + name + ", мне " + age + "лет")
println("Меня зовут $name, мне $age")
println("Меня зовут ${name.length}, ${age + 10}")
```

`+` склеивает строки. `$name` подставляет значение переменной. `${...}` позволяет подставить результат выражения. При соединении нескольких строк через `+` переносы строк в исходном коде сами по себе не добавляют переносы в результат.

Вывод этих примеров:

```text
Меня зовут Nikita, мне 24лет
Меня зовут Nikita, мне 24
Меня зовут 6, 34
```

В первом примере перед `лет` не хватает пробела. В третьем `name.length` означает длину строки: у `Nikita` она равна `6`; имя в этой строке не выводится.

### Многострочные строки

```kotlin
    val str3 = """ afgasdflsadkfkdsaf
                           asljfnaljsf
        fajnfasfjasf
                        asljfnsajl
    """
    println(str3)
    println(str3.trimIndent())
```

Многострочная строка, например `str3`, объявляется через тройные кавычки `""" ... """`. Такая строка сохраняет реальные переносы строк и пробелы из исходного текста. Обычные escape-последовательности вроде `\n` в ней не обрабатываются, но строковые шаблоны работают.

`println(str3)` выводит исходные отступы. `str3.trimIndent()` убирает общий минимальный отступ непустых строк, а также пустые первую и последнюю строки, если они есть. Различия в отступах между строками сохраняются: метод не выравнивает произвольно оформленный текст автоматически. В этом примере первая строка начинается с одного пробела после открывающих кавычек, поэтому общий минимальный отступ равен одному пробелу; заметные отступы последующих строк после обработки сохранятся.

### Сравнение и регистр

```kotlin
val str4 = "kotlin"
val str5 = "KOTLIN"
```

- `str4 == str5` даёт `false`: `==` сравнивает содержимое строк с учётом регистра.
- `str4 != str5` даёт `true`: строки различаются.
- `str4.uppercase() == str5.lowercase()` тоже даёт `false`: сравниваются `"KOTLIN"` и `"kotlin"`.

Для сравнения без учёта регистра нужно привести обе строки к одному регистру либо написать:

```kotlin
println(str4.equals(str5, ignoreCase = true)) // true
```

Строки неизменяемы: `uppercase()`, `lowercase()` и `trimIndent()` возвращают результат обработки, не меняя исходную строку.

## Ввод с консоли

```kotlin
println("Введите имя")
val myName = readln()
println(myName)
```

`readln()` читает строку ввода без завершающего перевода строки. Здесь введённое имя просто выводится обратно.

```kotlin
val (digit1, digit2) = readln().split(" ")
println("Число 1 = $digit1, Число 2 = $digit2")
```

`split(" ")` разделяет строку по пробелу и возвращает список строк. Запись `(digit1, digit2)` — деструктуризация: первые два элемента присваиваются двум переменным.

**Порядок выполнения:**

1. `readln()` получает одну строку.
2. `split(" ")` делит её по пробелу на части.
3. Деструктуризация записывает первую часть в `digit1`, вторую — в `digit2`.
4. Строковый шаблон подставляет обе части в сообщение.

При вводе `12 34` получится:

```text
Число 1 = 12, Число 2 = 34
```

Несмотря на имена `digit1` и `digit2`, их тип — `String`, а не числовой тип. Для вычислений потребуется преобразование. Если частей меньше двух, обращение ко второй завершится ошибкой; лишние части не попадут в эти переменные. Повторные пробелы могут создавать пустые части, поэтому такой ввод предполагает аккуратный формат, например `12 34`.

`readln().toDouble()` читает строку и преобразует её в дробное число, а `readln().toInt()` — в целое. Некорректный ввод в этих примерах не обрабатывается. Если ввод закончился, сам `readln()` также может выбросить исключение.

## Условия и логические операторы

```kotlin
val temp = readln().toDouble()

if (temp > 25) {
    println("Жарко")
} else if (temp < 0)
    println("Холодно")
else {
    println("Нормально")
}
```

Проверки идут сверху вниз, выполняется только одна подходящая ветка. При температуре выше `25` выводится `Жарко`, ниже `0` — `Холодно`, иначе — `Нормально`. Значения ровно `0` и `25` попадают в последнюю ветку. Фигурные скобки можно опустить для одиночного оператора, как в ветке `temp < 0`.

Логические операторы:

- `&&` — И: оба условия должны быть истинны.
- `||` — ИЛИ: достаточно одного истинного условия.
- `!` — НЕ: меняет логическое значение на противоположное.

У `&&` и `||` короткое замыкание: правое выражение не вычисляется, если результат уже понятен по левому.

### if как выражение

```kotlin
val desc = if (temp > 15) {
    println("temp > 15")
    15
} else temp.toInt()
```

`if` может возвращать значение. Если `temp > 15`, выполняется вывод и в `desc` записывается `15`, последнее выражение блока. Иначе записывается `temp.toInt()`: дробная часть отбрасывается в направлении нуля. Здесь `desc` имеет тип `Int`.

## when

`when` может использоваться как выражение: выбранная ветка определяет значение, которое записывается в переменную.

```kotlin
val day = readln().toInt()

val result = when (day) {
    1 -> "Понедельник"
    2 -> "Вторник"
    3 -> "Среда"
    in 4..5 -> "Четверг или Пятница" // Диапазон
    6,7 -> "Выходной"

    else -> "Это не день недели"
}
println(result)
```

Введённая строка преобразуется в `Int`, после чего `when (day)` проверяет номер дня:

| Значение day | Результат |
| --- | --- |
| `1` | `Понедельник` |
| `2` | `Вторник` |
| `3` | `Среда` |
| `4` или `5` | `Четверг или Пятница` |
| `6` или `7` | `Выходной` |
| Любое другое | `Это не день недели` |

`in 4..5` проверяет принадлежность диапазону. `6, 7` перечисляет два возможных значения одной ветки. `->` отделяет условие ветки от результата, `else` задаёт вариант по умолчанию. `println(result)` выводит выбранную строку.

## Диапазоны

```kotlin
val r1 = 1..5 // от 1 до 5 включительно
val r2 = 1 until 5 // от 1 до 4
val r3 = 5 downTo 1 // от 5 до 1 включительно
val r4 = 1.0..100.0
val r5 = 1..5 step 2 // от 1 до 5 с шагом 2
```

| Переменная | Выражение | Значения или смысл |
| --- | --- | --- |
| `r1` | `1..5` | `1, 2, 3, 4, 5` |
| `r2` | `1 until 5` | `1, 2, 3, 4`; верхняя граница исключена |
| `r3` | `5 downTo 1` | `5, 4, 3, 2, 1` |
| `r4` | `1.0..100.0` | Замкнутый диапазон дробных значений для проверок принадлежности |
| `r5` | `1..5 step 2` | `1, 3, 5` |

`step` задаёт положительную величину шага; направление определяется исходной последовательностью. Диапазон `Double`, как `r4`, нельзя напрямую перебрать обычным `for`: в нём не определён шаг перебора. Например, проверка `50.5 in r4` допустима.

## Циклы

### for

```kotlin
for (i in r3) {
    println(i)
}
```

Выводит числа от `5` до `1`. Переменная цикла `i` получает очередной элемент на каждой итерации.

Границы можно задавать переменными:

```kotlin
val r6 = 1
val r7 = 7

for (i in r6..r7) {
    println(i)
}
```

Этот цикл выводит числа от `1` до `7` включительно. Значения границ используются для построения диапазона, по которому затем идёт перебор.

### repeat

```kotlin
repeat(5) {
    println("Hi!")
}
```

Выполняет блок пять раз. Это вызов функции с лямбдой, удобный для фиксированного количества повторений. При необходимости внутри блока доступен индекс повторения `it`, начиная с нуля.

### while и do-while

```kotlin
var n = 0
// Цикл с предусловием
while (n < 100) {
    n += 25
    println(n)
}

var m = 0
// Цикл с постусловием
do {
    m += 25
    println(m)
} while (m < 100)
```

`while (n < 100)` сначала проверяет условие, затем выполняет тело. При `n = 0` и прибавлении `25` на каждой итерации выводит `25`, `50`, `75`, `100`.

`do { ... } while (m < 100)` сначала выполняет тело и только затем проверяет условие, поэтому тело выполнится хотя бы один раз. В примере с `m = 0` вывод тот же: `25`, `50`, `75`, `100`.

**Ход выполнения:** перед первой итерацией значение равно `0`; тело прибавляет `25` и печатает новое значение. После вывода `100` очередная проверка `< 100` даёт `false`, и цикл завершается. Различие двух циклов проявляется, если условие ложно уже до первого прохода: `while` не выполнит тело ни разу, а `do-while` выполнит его один раз.

### return, break, continue

- `return` выходит из текущей функции. Если он выполняется внутри вложенных циклов функции `main()`, завершается вся функция, включая оба цикла.
- `break` выходит из ближайшего охватывающего цикла. Если он стоит внутри вложенного цикла по `j`, завершается именно этот внутренний цикл.
- `continue` пропускает оставшуюся часть текущей итерации ближайшего цикла и переходит к следующей. Если он стоит непосредственно в теле внешнего цикла по `i`, его действие относится к этому циклу.

**Ключевое различие:** выход из всех вложенных циклов может быть следствием `return`, но его общее действие — завершение функции.

**Пример внутри функции `main()`:**

```kotlin
for (i in 1..10) {
    for (j in 1..10) {
        if (j == 3)
            return // Выход из функции main()

        if (j == 5)
            break // Выход из внутреннего цикла
    }

    if (i == 7)
        continue // Переход к следующей итерации внешнего цикла
}
```

**Разбор порядка выполнения:**

1. Внешний цикл начинает с `i = 1`, внутренний — с `j = 1`.
2. При `j = 1` и `j = 2` оба условия внутреннего цикла ложны.
3. При `j = 3` выполняется `return`, завершающий `main()`.
4. Условие `j == 5` с `break`, проверка `i == 7` с `continue` и последующий код функции не достигаются.

Если убрать условие с `return`, внутренний цикл будет завершаться при `j = 5`, после чего внешний продолжит работу. `continue` в конце тела внешнего цикла не пропускает дополнительных действий, поэтому в таком положении не меняет результат этой итерации.

## Функции

Параметр — имя в объявлении функции, аргумент — значение, переданное при вызове. Например, у `sum2(a: Int, b: Int)` параметры `a` и `b`, а у вызова `sum2(5, 6)` аргументы `5` и `6`.

### sum1: без параметров

```kotlin
fun sum1() {
    println(5 + 5)
}
```

Вызов `sum1()` выводит `10`. Функция не возвращает числовой результат: её возвращаемый тип — `Unit`.

### sum2: параметры и return

```kotlin
fun sum2(a: Int, b: Int): Int {
    return a + b
}
```

Принимает два `Int` и возвращает их сумму как `Int`. В `val sum5 = sum2(5, 6)` переменная получает `11`. Само присваивание ничего не выводит в консоль. Параметры `a` и `b` относятся к этой функции и не связаны с одноимёнными переменными в `main()`.

### sum3: тело-выражение

```kotlin
fun sum3(a: Int, b: Int) = a + b
```

Эквивалентна `sum2` для этих аргументов. Возвращаемый тип `Int` выведен из выражения справа от `=`. Это функция без явного указания возвращаемого типа, но с возвращаемым значением. `println(sum3(5, 6))` выводит `11`.

### create: значение параметра по умолчанию

```kotlin
fun create(a: Int, b: Int = 10) {
    println(a + b)
}
```

`create(5)` использует `b = 10` и выводит `15`. `create(5, 9)` использует переданное `b = 9` и выводит `14`. Функция возвращает `Unit`, а не сумму. Название `create` не описывает её фактическое действие: в этом примере она просто печатает сумму.

## Список, массив и доступ по индексу

### Список

```kotlin
val list = listOf(1, 2, 3, 4, 5)
println(list)
println(list[4])
```

`listOf()` создаёт список с интерфейсом только для чтения, здесь `List<Int>`. Выводится `[1, 2, 3, 4, 5]`, затем `5`. Индексы начинаются с нуля: пятый элемент имеет индекс `4`.

**Различие ссылки и объекта:** `val` запрещает заменить ссылку `list`, а `List` не предоставляет операций изменения элементов. Но интерфейс только для чтения не гарантирует неизменность элементов-объектов и не равнозначен универсальной гарантии неизменности коллекции. В этом примере список целых чисел используется только для чтения. Для изменения списка обычно выбирают `mutableListOf()`.

### Массив

```kotlin
val array = arrayOf(1, 2, 3, 4, 5)
array[0] = 5
```

`arrayOf()` создаёт `Array<Int>` фиксированного размера. Элементы можно заменять, поэтому после присваивания содержимое будет `[5, 2, 3, 4, 5]`. `val` этому не мешает: ссылка остаётся той же. Присваивание элементу массива само по себе не выводит его содержимое.

Размер массива нельзя увеличить добавлением элемента на месте. Для растущей коллекции удобнее изменяемый список. Для специализированного массива целых чисел есть `intArrayOf()`, создающий `IntArray`.

### Индексирование строки

```kotlin
val string = "Fsafasfasfas"
println(string[6])
```

`string[6]` возвращает `Char` на седьмой позиции. В данном примере это `f`. У строк, списков и массивов обращение за пределами допустимых индексов вызывает исключение.

## Пример: вызовы функций и вывод

Рассмотрим последовательность вызовов уже определённых функций и операций с коллекциями:

```kotlin
fun main() {
    sum1()
    val sum5 = sum2(5, 6)
    println(sum3(5, 6))
    create(5)
    create(5, 9)

    val list = listOf(1, 2, 3, 4, 5)
    println(list)
    println(list[4])

    val array = arrayOf(1, 2, 3, 4, 5)
    array[0] = 5

    val string = "Fsafasfasfas"
    println(string[6])
}
```

Разбор вывода:

1. `sum1()` печатает `10`.
2. `sum2(5, 6)` возвращает `11`, которое сохраняется в `sum5`; отдельной строки вывода нет.
3. `println(sum3(5, 6))` печатает `11`.
4. `create(5)` и `create(5, 9)` печатают `15` и `14`.
5. Выводятся весь список, его пятый элемент и седьмой символ строки. Изменение массива не сопровождается выводом.

Результат:

```text
10
11
15
14
[1, 2, 3, 4, 5]
5
f
```

## Главное

- **`val` запрещает переприсваивание, `var` разрешает.** Возможность менять содержимое объекта определяется отдельно от вида переменной.
- **Тип указывают явно или выводят из значения.** Деление двух целых чисел отбрасывает дробную часть, а числовые преобразования выполняются соответствующими методами.
- **Строковые шаблоны подставляют значения и выражения.** Записи `$variable` и `${expression}` позволяют собирать строку без цепочки сложений.
- **Ввод с консоли сначала является строкой.** Преобразование некорректного текста в число может вызвать исключение; методы `OrNull` позволяют получить `null`.
- **`if` и `when` могут возвращать значения.** Проверки выполняются по порядку, а логические `&&` и `||` используют короткое замыкание.
- **Границы диапазонов задают явно.** `..` включает обе границы, `until` исключает верхнюю, `downTo` задаёт убывание, `step` — величину шага.
- **`while` проверяет условие до тела, `do-while` — после.** `for` перебирает элементы, а `repeat` удобен для фиксированного числа повторений.
- **`return`, `break` и `continue` действуют по-разному.** Они завершают функцию, ближайший цикл или оставшуюся часть текущей итерации соответственно.
- **Возврат результата и печать — разные действия функции.** Параметры задаются при объявлении, аргументы передаются при вызове; значения по умолчанию можно не указывать.
- **Индексация строк, списков и массивов начинается с нуля.** Массив допускает замену элементов даже через `val`, а интерфейс `List` предоставляет доступ только для чтения.
